Use the GitHub tools to find recent merged pull requests that touched these files, and read the review comments left on them. Prefer comments that asked for a change over ones that only asked a question.

Report a comment when the current change repeats what it asked someone to avoid, or when it raises a concern that the current change runs into again. Give the file and line it applies to now, a link to the original comment, and what it asked for.

Report nothing else. A comment being about the same file is not enough; it has to apply to this change. If nothing applies, say so in one line.
